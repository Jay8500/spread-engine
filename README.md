# Spread Engine

Landing page for **engine.spreadapps.in** — a reusable Angular + Tailwind + Supabase + Netlify + Resend starter by Spread Apps™ (coming soon + waitlist).

- `npm start` → http://localhost:4200
- `npm run build` → prerendered static site in `dist/spread-engine/browser`
- Waitlist: `netlify/functions/waitlist.mts` (Netlify Blobs). Netlify env: `RESEND_API_KEY` (secret), `WAITLIST_EMAIL_TO`, `STATS_KEY`.
- Ads: fill `adSlots` in `src/app/shared/site.config.ts` after AdSense approval (empty = no ads, no script).
- Setup steps download: `public/downloads/spread-engine-setup-steps.md`.
